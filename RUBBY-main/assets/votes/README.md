# Game audio files

Place the provided sound files in this folder with these exact names:

- `button_click.mp3`
- `carrot_collect.mp3`
- `gameplay_music.mp3`
- `game_over.mp3`
- `lose_life.wav`
- `main_menu_music.mp3`
- `win.mp3`

`AudioManager` loads these paths from `res://assets/votes/` and safely skips any file that is not present.
